## I finally hit "deploy"

A personal portfolio is typically the sort of project that is forever one more edit away from completing.
This time, I utilised Claude Code to truly bring the site to life.
Taking inspiration from more retro-ASCII style websites and blending it with a clean, static, purple UI allowed me to move from concept to implementation at astonishing speed.

👉 **See it live at [ravjothbrar.com](https://www.ravjothbrar.com)**
